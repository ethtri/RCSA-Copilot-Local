# Legacy Power Pages References
This folder is the parking spot for context-only artifacts pulled from the prior Power Pages implementation. Keep these documents referenced in governance materials, but do not use them as the primary source for static build instructions.

## Migration Guidelines
- Move any remaining portal-exported HTML, CSS, or screen captures here instead of embedding absolute paths (e.g., `C:\Projects\RCSA_Demp_V6\...`) in active checklists.
- Label files clearly (e.g., `home-portal-reference.md`, `wizard-stepper-portal.html`) and include a short note describing the insight they provide for the static rebuild.
- When a legacy reference informs a static decision, cite it from governance docs (delivery plan, DoD, decision register) so the lineage stays transparent.
