# Design

The source of truth is [the existing design system](../../docs/ux/DEMO_EXPERIENCE_DESIGN.md) and src/styles/upgrade.css. This document records its current conventions; it does not replace them.

Light work surfaces on a pale cool canvas, restrained forest-green actions, subtle boundaries and 6px control / 8px panel radii. Segoe UI/system sans for operational content; one 32px serif page title. Body text 14–16px with 1.5–1.7 line height. Metadata 12–13px. Spacing scale 4/8/12/16/20/24/32px, normal controls at least 44px. Use separate metadata, heading, explanation and action groups. Details, sources, history and method are secondary disclosures. Source drawers preserve editor state; long editors have one scroll region. Motion is short, conveys state and respects reduced motion.
